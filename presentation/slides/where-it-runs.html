Im BrowserIn the browser

Eine Internetseite, die nichts installiert und nichts überträgt: eine HTML-Datei, zwei JavaScript-Dateien, die Fragedaten und je Sprache eine Textdatei. Keine Anmeldung, kein Konto, kein Modell.A web page that installs nothing and transmits nothing: one HTML file, two JavaScript files, the question data and one text file per language. No sign-in, no account, no model.

Jedes Paket wird im Prüflauf gestartet, bevor es veröffentlicht wirdEvery package is started in the check run before it is published

„Läuft ohne Installation" heißt hier wörtlich: die Internetseite ist eine Datei, die im Browser rechnet. Es gibt keinen Dienst dahinter, der Antworten entgegennehmen könnte. Und „läuft ohne Netz" wird im Container nachgeprüft: der Dienst wird mit abgeschaltetem Netz gestartet und muss antworten — dazu wird geprüft, dass das Netz wirklich fehlt, sonst wäre die erste Prüfung wertlos.“Runs without installation” is meant literally here: the web page is a file that computes in the browser. There is no service behind it that could receive answers. And “runs offline” is checked in the container: the service is started with networking switched off and must answer — and the check also confirms that the network really is absent, otherwise the first check would be worthless.
