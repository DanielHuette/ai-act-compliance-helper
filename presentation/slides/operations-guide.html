In drei Stufen vom Ausprobieren zum BetriebFrom first try to production in three steps

1

Nur ausprobieren: nichts tunJust trying: do nothing

Die Internetseite aufrufen und die Fragen beantworten. Es gibt nichts zu installieren und nichts anzumelden; die Einstufung rechnet der Browser.Open the web page and answer the questions. There is nothing to install and no sign-in; the browser computes the classification.

2

Auf dem eigenen Rechner: das PaketOn your own computer: the package

Von der Veröffentlichungsseite das Paket für Windows, Mac oder Linux holen, installieren, starten. Die Bedienoberfläche öffnet sich im Browser. Rechtsbestand und Regelwerk liegen dabei — es wird nichts nachgeladen.Download the package for Windows, Mac or Linux from the releases page, install, start. The interface opens in the browser. Legal corpus and rule set are included — nothing is downloaded later.

3

Aus dem QuelltextFrom source

Repository holen, dann pip install -e . und python packaging/launch_app.py. Als Container: ./scripts/start.sh. Wer im Verordnungstext suchen will, baut je Sprache einmal den Suchbestand — die Einstufung wartet nicht darauf.Clone the repository, then pip install -e . and python packaging/launch_app.py. As a container: ./scripts/start.sh. Anyone who wants to search the legal text builds the search index once per language — the classification does not wait for it.

Für eigene AbläufeFor your own workflows

compliance-helper classify „...““...”
compliance-helper ask „...““...”
compliance-helper search „Art. 6 Abs. 3““Article 6(3)”
compliance-helper status
compliance-helper serve

Mit --json wird die Ausgabe weiterverarbeitbar, mit --lang en englisch — etwa für eine nächtliche Prüfung aller Systeme eines Unternehmens.With --json the output can be processed further, with --lang de it is German — for a nightly check of all systems of a company, say.

/health nennt Zustand, Rechtsstellen, Stand des Regelwerks und Suchmodell — und sagt, wenn der Suchbestand fehlt./health reports status, legal units, rule set version and search model — and says so when the search index is missing.

Die Reihenfolge ist die Reihenfolge des Einstiegs: wer wissen will, ob das Werkzeug ihm hilft, braucht Stufe 1 und sonst nichts. Stufe 3 ist die einzige mit Wartezeit, und sie betrifft nur das Nachlesen. Darum sagt der Dienst von selbst, wenn er mit dem Ersatzverfahren sucht: dann vergleicht er nur Wörter statt Bedeutung, und die Fundstellen sind deutlich schlechter. Schlüssel für ein Sprachmodell kommen aus der Umgebung, nicht aus einer Datei im Repository; die Vorlage steht in .env.example.The order is the order of getting started: anyone who wants to know whether the tool helps them needs step 1 and nothing else. Step 3 is the only one with a wait, and it only affects looking things up. That is why the service says on its own when it searches with the fallback: it then compares words instead of meaning, and the passages found are noticeably worse. Keys for a language model come from the environment, not from a file in the repository; the template is .env.example.
