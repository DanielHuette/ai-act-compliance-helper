Vier Angriffswege, jeder einzeln verbautFour attack routes, each one closed off

Untergeschobene AnweisungenInjected instructions

Die Beschreibung des Nutzers steht zwischen zwei je Anfrage gewürfelten Marken. Wer eine Abschnittsgrenze nachbauen will, müsste sie erraten.The user's description sits between two markers drawn at random for each request. Faking a section boundary would mean guessing them.

Erprobt mit 10 Angriffen, je zweifach geprüft.Tested with 10 attacks, each checked twice.

Erfundene FundstellenInvented citations

Jeder Artikel in der Antwort muss in den Belegen stehen. Was nicht belegt ist, wird gemeldet.Every article in the answer must appear in the evidence. Anything unsupported is reported.

So fiel auf, dass Artikel 72 im Pflichttext stand, aber nicht in den Fundstellen.That is how Article 72 was caught in an obligation text but missing from its citations.

Der Bestand als AngriffswegThe index as an attack route

Als pickle hätte eine veränderte Kopie beim Laden fremden Code ausgeführt. Jetzt JSON: falsche Treffer sind möglich, fremder Code nicht.Stored as a pickle file, a tampered copy would have run foreign code on load. Now JSON: wrong hits are possible, foreign code is not.

Im BetriebIn operation

Der Container läuft ohne Verwalterrechte und kann seinen Quelltext nicht ändern. Schlüssel nie im Protokoll. 30 Anfragen je Minute. Keine Verbindung nach außen.The container runs without administrator rights and cannot change its own code. Keys never in the log. 30 requests per minute. No outbound connection.

Schwachstellenmeldungen: SECURITY.md · Sicherheitsmodell: docs/security.de.mdVulnerability reports: SECURITY.md · Security model: docs/security.md

Der dritte Punkt ist der, der am leichtesten übersehen wird. Im Quelltext stand als Begründung „eigene Datei, kein Fremdinhalt" — das stimmte nicht: die Datei wird mit ausgeliefert, und wer eine Kopie des Repositories ändert, erreicht damit jeden, der sie lädt. Die Prüfwerkzeuge brechen ab, statt zu warnen: ruff, ruff format, mypy, bandit und pip-audit laufen ohne Beanstandung, damit ein roter Lauf wieder etwas bedeutet.The third point is the easiest to overlook. The code once justified it with “own file, no foreign content” — that was wrong: the file ships with the repository, and anyone who changes a copy reaches everyone who loads it. The check tools fail instead of warning: ruff, ruff format, mypy, bandit and pip-audit pass without findings, so a red run means something again.
